# crabby-beach-run
Crabby Beach Run! 🦀 A HTML5 Javascript game created by Claude AI, with a p5.js version created by me.

Here's how to play:

- Space / Click / Tap to jump (double jump is allowed!)
- Dodge the seashells washing up on the beach
- Clouds scroll in the background as you run
- Speed increases the longer you survive
- You have 3 lives — flicker means you're temporarily invincible after a hit
